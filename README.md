# Happy Birthday, Prerna

A cinematic birthday film in four acts: draw a Cupid’s bow, strike the heart, watch a rose flood, then a blossom tree grows into a wish.

Built with vanilla JS, Vite, and GSAP (one canvas, no framework).

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (default: [http://127.0.0.1:43127](http://127.0.0.1:43127)).

## How to play

1. Pull the bowstring down (drag, or press Space / Enter).
2. Release to fire — the heart bursts into a birthday wish.
3. Watch the tree bloom; tap **Again** to replay.

## Build

```bash
npm run build
npm run preview
```
